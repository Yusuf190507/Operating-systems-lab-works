# Отчет по лабораторной работе N <1> по курсу
# "Операционные системы"

### Задание:
Необходимо составить программу процесса, принимающего на вход название файла, который будет обрабатывать команды типа: “Число<endline>”. Затем процесс должен создать дочерний процесс, которому будет отправлено данное число. Если число окажется составным, наследник должен записать его в файл, иначе — родительский и дочерний процессы завершаются.

### Запуск программ:

1. Компиляция `parent.c`:
```C
gcc parent.c -o parent
```

2. Компиляция `child.c`:
```C
gcc child.c -o child -lm
```

3. Запуск родителя:
```C
./parent filename
```

4. Ввод данных (если что, программа сама подскажет).
